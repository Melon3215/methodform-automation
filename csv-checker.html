자주 묻는 질문

검사 방식과 한계

파일이 인터넷으로 전송되나요?

아니요. 이 검사기는 파일의 내용을 브라우저에서만 읽습니다. 검사 결과를 서버에 보내거나 저장하지 않으며, 탭을 닫으면 분석 내용은 사라집니다. 민감한 파일은 사용 환경과 브라우저 확장 프로그램도 확인하세요.

같은 행인지 어떻게 판단하나요?

선택한 기준 열들의 값이 같은지를 확인합니다. 공백·영문 대소문자·호환 문자 차이를 정규화합니다. 두 번째 등장부터 중복으로 표시합니다. 열 개수가 다른 행과 기준값이 비어 있는 행은 따로 표시합니다.

엑셀 파일(xlsx)도 지원하나요?

현재는 쉼표·탭·세미콜론 구분의 UTF-8 텍스트 CSV만 지원합니다. Excel에서 ‘CSV UTF-8’로 저장해 검사하세요. 복잡한 엑셀 자동화는 맞춤 문의를 이용해 주세요.

검사하면 중복이 자동 삭제되나요?

아니요. 원본 보존을 우선해 중복 여부와 최초 등장 행을 표시한 리포트만 저장합니다. 실제 삭제·병합 작업은 데이터별 기준과 확인 절차가 필요합니다.
